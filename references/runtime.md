# 运行与改造

## 工程入口

将 `assets/starter/` 复制到任务目录。在副本中修改封面、正文、讲稿和选项，再打包到独立的 HTML 路径。默认样例《屋顶上的 100 升雨水》是虚构水量示意，用来验证不同题材也能沿用这一播放方式。

| 文件 | 修改范围 |
|---|---|
| `index.html` | 页、节拍、场景 DOM、证据和讲稿 |
| `demo.css` | 材质、色彩、字体、构图、竖屏布局、题材动作 |
| `demo.js` | 道具内容、配色、图表数据、自己的节拍事件 |
| `player.js`、`player.css` | 共享播放、控制、画布缩放、转场 |
| `motion.js` | 书本、纸层两个独立实时道具 |

## 写一页

```html
<section class="slide" data-title="页标题" data-chapter="章节"
         data-beats="3" data-transition="leaf" aria-labelledby="s-title" hidden>
  <h2 id="s-title">页标题</h2>
  <p data-in="1">第二次看到的内容</p>
  <p data-in="2">最后留在屏幕上的结论</p>
  <p class="speaker-note" hidden>这一页的讲稿。</p>
</section>
```

第一张 `section.slide` 不加 `hidden`。`data-beats` 表示整页共几拍，索引从 0 开始。没有 `data-in` 的元素默认第一拍可见。点击画面空白处、滚轮或左右键逐拍走。用 `data-interactive` 标出画布拖动区、自定义控件等需要隔离翻页的区域。

`data-transition` 支持 `leaf`（纸叶）、`iris`（镜头过渡）、`ink`（墨渍式遮罩）、`cut`（直切）。切页中途换画，短暂锁定重复输入。给 `data-motion` 写 `cover`、`close` 或 `sheets` 可挂载自带道具。保留不同道具所需的画布位置和尺寸。配置方法见 [实时道具](motion.md)。

```js
document.addEventListener("yd:beat", ({detail: {index, beat, slide}}) => {
  // 按当前页和节拍同步图表或摆位。也要处理回退和重播。
});
```

把交互状态和更新函数放在题材脚本中。交互控件应可键盘操控，选中时更新 `aria-pressed` 或对应可访问语义。数据图表动画要和数值共用一份数据。举例、拟合、模拟和实测分别标注，动画结束后轴和单位保持清楚。若引入代码绘图，DOM 中仍留可阅读的关键值与结论。

## 画幅、资产与打包

- 桌面按 1600 × 900 构图并等比缩放，竖屏可用 `.portrait` 排版规则重排至 960 × 1540。更换长宽比时同时检查演示控件，以及全屏进入和退出。
- 图片可生成、经授权使用或原创绘制。依用途给背景、前景和遮罩留空间，剪裁压缩后再内联。选用系统字体，或将确有权分发的字体内联。
- 用 `{{asset:media/scene.webp}}` 标注需内联的相对资源。它可写在 `<img src="...">`、CSS `url("...")` 或文本脚本的资源字符串中。打包器替换为 Data URL。输入文件、样本事实和背景资产按共享范围选取。
- 无论选用哪个引擎，离线成品应可在 `file://` 打开。避免运行时动态加载旁置资源、远程字体和 CDN。来源链接可供观众主动联网访问。

```sh
python -X utf8 scripts/pack.py path/to/story.html --project path/to/copied-starter
```

首次直接跑仓库里的样例可省略 `--project`。复制时保留 `index.html` 中打包占位注释。自带脚本和样式按打包器固定顺序加载。删除某个模块时更新打包器或保留对应空文件。

## 浏览器验收

- 先看开场和核心证据页的三个时刻。初始镜头是否能定位主体，动作中间是否有透视、遮挡或层次变化，稳定以后能否读清图例和范围。
- 顺走、反走和跳页，至少测试一次人工切换图表或动作。检查目录、讲稿、可见焦点、触屏、全屏进出及屏幕尺寸变化。
- 减少动态效果模式下，章节和证据的顺序保持可访问，粒子、摄像机漂移和高频光线暂停。
- [检查脚本](../scripts/check_deck.py) 使用 Chromium 和 Playwright 验证此播放器的结构、离线行为和控制，支持导出预览截图。依赖按需安装，播放 HTML 本身只需浏览器。
- README 的动态图用浏览器真实录制，保留帧间变化和最终读数。短画面优先展示一次具体而可复述的动作，例如折页打开或证据随样本切换重绘。
